# 30-Day Content Calendar — How to Use It

Open `content-calendar-30days.csv` in:
- **Google Sheets** (File → Import → Upload)
- **Excel** / Numbers (double-click)
- **Notion** (paste as a database)
- **Airtable** (Import CSV)

---

## Columns explained

| Column | What it's for |
|---|---|
| **Day / Date offset / Weekday** | When to post (D+0 = today). Adjust to your start date. |
| **Format** | Reel / Carousel / Story-only day. Follows the schedule from the growth strategy. |
| **Hook / Title** | The first line viewers see. Already optimized to stop the scroll. |
| **Angle** | Why this post exists (Education / Hook / Proof / Personal). |
| **Caption opener (FR)** | First line of your caption. Build the rest of the caption around it. |
| **CTA** | The single action you want the viewer to take. ONE per post. |
| **Hashtag pack** | Reference key (see packs below) — paste 8–12 hashtags accordingly. |
| **Story of the day** | What to post in your stories that day to reinforce the feed post. |
| **Status** | Move to "Filmed" → "Edited" → "Scheduled" → "Posted" as you go. |

## How to actually run this

1. **Sunday batch day** → film 3 Reels + design 2 carousels for the week.
2. **Schedule via Meta Business Suite** (free) → Reels + carousels go up automatically Mon/Tue/Thu/Fri/Sat/Sun.
3. **Stories you do live** every morning (5 min, follow the "Story of the day" column).
4. **Wednesday** is intentionally feed-free → Q&A / engagement day. The algorithm rewards accounts that don't post every day if engagement on off-days is high.
5. **Track the Status column** so nothing slips.

## After 30 days

Open Instagram Insights → for each post type rank by:
- Reach (Reels)
- Saves (Carousels)
- DMs received (Proof posts)

→ Take the **top 3 posts** of the month.
→ Make 3 new variations of each.
→ That's your month 2 calendar.

This is how growth compounds. You stop guessing and start replicating winners.
